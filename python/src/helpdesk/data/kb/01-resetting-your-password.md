# Resetting your password
tags: account, password, login

## Send yourself a reset link

On the sign-in page, choose the Forgot password link and enter the email address you signed up with. We send a reset link to that address. Use the link to choose a new password; the old one stops working at once.

## If the reset email doesn't arrive

Reset emails can take up to ten minutes to arrive, and they sometimes land in the spam folder. Check your spam folder, then use the Forgot password link again. If you signed up through single sign-on, you have no password with us: sign in with your company account instead.

## Reset links expire

A reset link works once, and it expires 30 minutes after we send it. If yours has expired, request a new one. Only the newest link works.
