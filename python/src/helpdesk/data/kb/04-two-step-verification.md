# Two-step verification
tags: security, login, 2fa

## Turning it on

Open Settings, then Security, and choose Turn on two-step verification. Scan the code with an authenticator app, then enter the six-digit code it shows. We then show ten backup codes: save them somewhere safe.

## If you lose your phone

Sign in with one of your backup codes instead of the six-digit code. Each backup code works once. Then turn two-step verification off and on again with your new phone. If you have no backup codes left, a workspace owner can reset two-step verification for you.

## Error E-2231: code rejected

Error E-2231 means the six-digit code didn't match. The usual cause is the clock on your phone: authenticator codes depend on the time. Set your phone to set its time automatically, then try a fresh code.
