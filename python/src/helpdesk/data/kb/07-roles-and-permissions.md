# Roles and permissions
tags: roles, admin, permissions

## The four roles

A workspace has four roles. The owner controls billing and can delete the workspace. Admins manage members and settings. Members create and edit projects. Guests see only the projects they are added to, and can comment but not edit.

## Transferring ownership

A workspace has exactly one owner. To hand it to someone else, the owner opens Settings, then Members, and chooses Make owner beside an admin. The old owner becomes an admin. Only an admin can become the owner.

## Removing someone

Removing a member doesn't delete their work. Their projects and tasks stay in the workspace, and an admin can reassign them.
