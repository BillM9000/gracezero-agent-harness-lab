# Importing from a spreadsheet
tags: import, csv, spreadsheet

## Importing a CSV

In a project, choose Import, then pick a CSV file. The first row must hold column names. Each following row becomes one task.

## Error E-3107: column not recognized

Error E-3107 means a column name in the first row isn't one we know. The names we recognize are Title, Description, Assignee, Due date and Status. Rename the column, or remove it, and import again.

## Limits

One file can hold up to 5,000 rows. Split a bigger spreadsheet into several files and import them one after another.
