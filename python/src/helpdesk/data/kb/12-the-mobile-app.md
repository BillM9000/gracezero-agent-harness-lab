# The mobile app
tags: mobile, offline, sync

## Working offline

The mobile app keeps your recent projects on the device, so you can read and edit tasks without a connection. Changes sync when the app is back online.

## Sync conflicts

If the same task was changed on two devices while one was offline, the newest change wins, and the older one is kept in the task's history. Open the task's history to copy anything back.

## If the app crashes on start

Update the app to the latest version first. If it still crashes, open your phone's settings and clear the app's cache, then sign in again. Clearing the cache removes nothing that has already synced.
